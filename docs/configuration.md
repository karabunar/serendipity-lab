# Configuration

Everything is configured through environment variables. Common to all jobs: `REDIS_ADDR`
(`localhost:6379`), `REDIS_PASSWORD`.

| Job | Variables |
|---|---|
| `curated-booster` | `CURATED_MIN_AGE`, `CURATED_QUALITY_THRESHOLD`, `CURATED_TEXT_LEN_NORM`, `CURATED_MEDIA_BONUS`, `CURATED_LLM_QUALITY_THRESHOLD`, `CURATOR_GRPC_ENDPOINT` (empty = no LLM scoring), `CURATOR_GRPC_TIMEOUT`, `CURATOR_GRPC_USE_TLS` |
| `niche-profiler` | `NICHE_PROFILER_ENABLED`, `LOCAL_LLM_BASE_URL`, `LOCAL_LLM_MODEL` (both required), `LOCAL_LLM_API_KEY`, `LOCAL_LLM_TIMEOUT`, `EMBED_GRPC_TARGET` (`localhost:50061`), `NICHE_ACTIVE_KEY` |
| `user-interest` | `USER_INTEREST_ENABLED`, `USER_INTEREST_{DECAY_STABLE,DECAY_RECENT,MAX_ENTITIES,QUERY_TOP_K,MIN_QUERY_WEIGHT,RING_LIMIT,LOOKBACK_DAYS,TTL,BATCH_SIZE,WORKERS,SINCE_GRACE,ACTIVE_KEY}`, `USER_INTEREST_GRAPH_{ENABLED,WEIGHT,MAX_AUTHORS,POSTS_PER_AUTHOR}` |
| `post-indexer` | `POST_INDEXER_ENABLED`, `POST_INDEXER_BATCH` (64), `POST_INDEXER_MAX_POSTS` (0 = unlimited), `EMBED_GRPC_TARGET`, `QDRANT_URL` (`http://localhost:6333`), `QDRANT_API_KEY`, `QDRANT_COLLECTION` (`serendipity_posts`) |
| `entity-link-builder` | `ENTITY_LINK_BUILD_ENABLED`, `ENTITY_LINK_{BATCH_SIZE,MAX_POSTS,MIN_CANONICAL_COUNT,MAX_MAPPINGS}` |
| `embedding_service` | `EMBEDDING_MODEL`, `EMBEDDING_DEVICE` (`cpu`), `EMBEDDING_PORT` (`50061`), `EMBEDDING_BATCH` (32) |

Metrics for the jobs that expose them are served on `METRICS_ADDR` (`:2112`); set
`METRICS_ENABLED=false` to turn that off.
